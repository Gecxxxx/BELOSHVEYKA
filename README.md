# Белошвейка — версия 4.0

React + Vite с предварительным рендером всех публичных страниц. Существующий чёрно-бело-жёлтый стиль, локальные шрифты Oswald и Manrope.

## Запуск и проверка

```sh
npm ci
npm run dev
npm run build
npm test
npm run test:sites
```

Результат сборки: `dist/client`. Совместимость с Sites сохранена: `dist/server/index.js`, `dist/.openai/hosting.json`. На Cloudflare Pages публикуется `dist/client`, сборка `npm run build`. Для Nginx: `try_files $uri $uri/ =404;` и `error_page 404 /404.html;`.

## Что входит в v3

- Главная, пошив на заказ, услуги, нанесение логотипа, кейсы/отзывы, как заказать и контакты.
- Каталог из 23 товаров и 6 категорий, страницы товаров, поиск, фильтры, сортировка, размеры и перенос выбранного товара в заявку.
- Реальные фотографии: 14 выбранных кадров с Яндекс Диска и изображения действующего каталога. Локальные WebP, адаптивные размеры. Источники и размеры — `docs/photo-manifest.json`.
- Подтверждённые условия: ассортимент от 10 шт., пошив вне ассортимента от 200 шт., 100% предоплата, самовывоз; срочное нанесение на складские позиции +20% по согласованию.
- Сертификат: оригинальный PDF и лёгкое превью; отдельное описание области применения.
- Реквизиты ИП, реальные контакты, фактическое описание обработки данных и передачи заявки.

## Редактирование

- `src/data.js`: контакты, условия, FAQ, направления и реестр страниц.
- `src/catalog-data.js`: товары, цены, размеры, характеристики и изображения. Наличие всегда требует подтверждения, складская интеграция отсутствует.
- `src/image-data.js`: реальные размеры адаптивных фотографий.
- `src/components/Catalog.jsx`: каталог и карточка товара.
- `src/components/RequestForm.jsx`: подготовка обращения и передача контекста товара.
- `docs/content-v3.md`: источники, ограничения и вопросы для наполнения.

## Заявки

Форма проверяет ввод и **локально** готовит текст. Пользователь сам отправляет его через свою почтовую программу или Авито; можно скопировать/скачать текст. Имена выбранных файлов включаются в описание, сами файлы не загружаются и должны быть приложены пользователем. Телефон доступен во всех ключевых точках. Ложных сообщений об отправке нет.

Серверную доставку заявок, загрузку файлов, Telegram и сбор персональных данных подключать отдельным этапом после настройки получателя, инфраструктуры и соответствующих документов. Текущие страницы данных описывают только фактический локальный режим, а не готовую политику будущей серверной системы.

## Публикация и данные

Индексация превью закрыта в robots.txt. Перед запуском основного домена: утвердить домен, подготовить canonical/sitemap и карту старых URL, подключить аналитику по согласованной схеме и открыть индексацию. Существующие адреса направлений сохраняются.

Клиентские кейсы и отзывы не выдуманы: на странице представлены реальные фотографии изделий и ссылка на оригинальные отзывы. Подробные истории проектов добавляются после получения фактов и материалов.

Сертификат относится к указанному в нём хлопчатобумажному трикотажу, а не к каждому товару каталога. Оригинальный документ сохранён без изменений.

## Визуальная доработка после v3

Спокойная типографика Manrope, заголовки обычным регистром, светлые вводные блоки внутренних страниц и обработанные фотографии в оформлении. Стилевые уточнения находятся в `src/refinement.css`. В основном меню доступны все семь внутренних разделов; главная открывается через логотип.

Три композиции из `public/assets/editorial/` подготовлены встроенным ImageGen на основе предоставленных снимков и экспортированы в WebP с мобильными вариантами (всего около 214 КБ). В каталожных галереях сохранены исходные фотографии. Происхождение и параметры: `docs/editorial-photos.json`, описание обработки: `docs/image-prompts.md`. План недостающей съёмки по страницам: `docs/photo-brief.md`.

## Версия 4: фотографии по смыслу разделов

Пять новых предметных ИИ-иллюстраций, семь дополнительных реальных ракурсов, отдельные изображения для направлений и категорий. У вводного блока больше нет фотографии по умолчанию. Контакты и документы открываются без случайной модели. Галереи услуг показывают соответствующие изделия или материалы.

Выбор изображений: `src/visuals.js`. Карта размещения и происхождение: `docs/photography-v4.md`, `docs/concept-photos-v4.json`, `docs/real-photos-v4.json`. Промпты: `docs/image-prompts-v4.md`.
