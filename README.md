# Белошвейка

Первая многостраничная версия сайта контрактного швейного производства. React + Vite, предварительный рендер HTML для каждого маршрута. Локальные шрифты Oswald и Manrope, изображения WebP, иконки Phosphor.

## Запуск

```sh
npm ci
npm run dev
npm run build
npm test
```

Результат сборки: `dist/client`. Отдельные HTML-страницы главной, направлений, пяти услуг, возможностей, условий, компании, примеров, контактов, конфиденциальности и 404. Для Nginx используйте `try_files $uri $uri/ =404;`, `error_page 404 /404.html;`.

## Важные ограничения первой версии

- Не интернет-магазин: нет цен, остатков, корзины и оплаты.
- Форма **не отправляет данные**. Она проверяет ввод, готовит текст заявки для скачивания и предлагает передать его через Авито. Прикреплённые файлы не загружаются на сервер; их нужно передать самостоятельно. Нет ложного сообщения об отправке.
- Подключение Telegram/email/CRM выполняется после выбора приёмщика и настройки серверных секретов. Не размещайте секреты в VITE-переменных.
- Телефон, адрес и реквизиты не выдуманы: до подтверждения используется предоставленная ссылка Авито.
- Рейтинг 5,0 / 6 отзывов взят с предоставленного скриншота; это не live-виджет. Реальные цитаты не получены и не выдумывались.
- Изображения AI используются для иллюстрации направлений, не как доказательства реализованных проектов или реального цеха. Перед запуском заменить/дополнить проверенными фото.
- Основной объём 1000 единиц одной модели в месяц указан в описании объявления. Заголовок объявления говорит об объёме от 100 единиц — минимальный заказ нужно уточнить у клиента.
- Юридическая страница описывает демонстрационную форму и должна быть заменена утверждённой политикой перед сбором данных.
- Индексация закрыта robots.txt для первой версии. Перед продакшеном утвердить домен, открыть индексацию, добавить canonical, sitemap и аналитику.

## Дизайн

Сохранены выбранные композиции. Заголовки и основной текст — 400, акценты — максимум 500. Блок «Что производим»: информация слева, фото справа. Отдельный блок «Производство» исключён. Все решения и источники перечислены в `design-decisions.md`.
